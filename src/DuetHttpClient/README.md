# DuetHttpClient

Official remote HTTP API client for Duet3D boards by Duet3D.

This package provides classes to connect to Duet 3 boards over HTTP in both standalone and SBC mode, allowing applications to query and subscribe to the object model, send G/M/T-codes and transfer files.

## Documentation

See the [DSF documentation](https://duet3d.github.io/DuetSoftwareFramework/index.html) for details.
