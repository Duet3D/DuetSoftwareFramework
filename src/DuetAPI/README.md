# DuetAPI

Official API library for Duet Software Framework (DSF) by Duet3D.

This package provides the shared data types used across DSF, including the object model, command definitions, connection message formats and JSON serialization helpers. It is consumed by the other DSF client libraries and can be used to build applications that interact with Duet 3 boards.

## Documentation

See the [DSF documentation](https://duet3d.github.io/DuetSoftwareFramework/index.html) for details.
