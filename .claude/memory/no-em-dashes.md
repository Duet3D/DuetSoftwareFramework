name: no-em-dashes
description: Never use em dashes as sentence punctuation; use commas, semicolons, or colons
metadata:
  type: feedback
---

Do not use em dashes (" — ") as punctuation within sentences. Use commas, semicolons, or colons instead.

**Why:** Stylistic preference of the user; em dash use reads as generated text.

**How to apply:** Applies to all written output, including chat responses, docs, commit messages, and code comments. Rephrase the clause with the appropriate punctuation rather than substituting a hyphen. See also [[writing-style-direct-technical]].
