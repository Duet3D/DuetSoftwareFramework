Default evaluation context that resolves nothing locally: every identifier and function call reports that it must be forwarded to the firmware, so any expression that depends on one is not evaluated on the SBC. Context-sensitive constants take their neutral values. Used as the fallback when no richer context is supplied (e.g. in unit tests of the pure parser core)
