Recursive-descent evaluator for meta G-code expressions. This is a C# port of the firmware ExpressionParser so that DSF can evaluate expressions itself instead of forwarding them to the firmware. Operator precedence, type coercion, numeric promotion rules and error messages are kept identical to the firmware to avoid behavioural drift.

Values are represented as boxed CLR objects matching the firmware type codes: null (none/null), bool, char, int (int32), uint (uint32), long (uint64), float, string, DateTime, DriverId and object?[] (array)

When the expression references something that cannot be resolved on the SBC, evaluation is abandoned (without throwing) and TryEvaluate(string, IExpressionEvaluationContext?, out object?) returns false so the caller forwards the original expression to the firmware. Only genuine syntax errors throw a CodeParserException.
