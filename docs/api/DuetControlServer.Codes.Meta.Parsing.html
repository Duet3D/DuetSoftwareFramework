Namespace DuetControlServer.Codes.Meta.Parsing

Classes

ForwardingExpressionContext

Default evaluation context that resolves nothing locally: every identifier and function call reports that it must be forwarded to the firmware, so any expression that depends on one is not evaluated on the SBC. Context-sensitive constants take their neutral values. Used as the fallback when no richer context is supplied (e.g. in unit tests of the pure parser core)

MetaExpressionParser

Recursive-descent evaluator for meta G-code expressions. This is a C# port of the firmware ExpressionParser so that DSF can evaluate expressions itself instead of forwarding them to the firmware. Operator precedence, type coercion, numeric promotion rules and error messages are kept identical to the firmware to avoid behavioural drift.

Values are represented as boxed CLR objects matching the firmware type codes: null (none/null), bool, char, int (int32), uint (uint32), long (uint64), float, string, DateTime, DriverId and object?[] (array)

When the expression references something that cannot be resolved on the SBC, evaluation is abandoned (without throwing) and TryEvaluate(string, IExpressionEvaluationContext?, out object?) returns false so the caller forwards the original expression to the firmware. Only genuine syntax errors throw a CodeParserException.

Interfaces

IExpressionEvaluationContext

Context supplying the environment-dependent parts of an expression evaluation: the values of context-sensitive constants and the resolution of identifiers (object model fields, variables) and function calls. The pure parser core (operators, literals, coercion) does not depend on this; only the parts that need to look something up in the running system do
