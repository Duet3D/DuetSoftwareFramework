# DuetSoftwareFramework Developer Documentation

This directory contains developer plans & implementation reasoning documents for **DuetSoftwareFramework (DSF)**

For the list of commands DSF has to cover:
- [GCODE_COVERAGE.md](GCODE_COVERAGE.md) - every GCode command documented for RRF 3.7, with
  columns for tracking regression tests, system tests and completeness.

[KNOWN_BUGS.md](KNOWN_BUGS.md) is a placeholder to prevent Github Issues getting overrun by experimental/dev issues.

For documentation about the using DSF:
- [Duet Wiki](https://docs.duet3d.com)

For documentation about how DSF functions:
- [DSF Wiki](https://duet3d.github.io/DuetSoftwareFramework/index.html)
    - Created from [src/Documentation/articles](../../src/Documentation/articles) and the source code comments.
